Practical decision framework (step‑by‑step)
1. Define must‑haves: number of users, dispatch vs. single‑tech scheduling, QuickBooks sync, payment processing, price book for plumbing, API needs.  
2. Narrow to 1–2 vendors:  
   - If you’re solo or 1–3 techs and want low entry cost + quick setup → start with Jobber Core/Connect and test the workflow [Jobber pricing and Core docs](https://www.getjobber.com/pricing/), https://help.getjobber.com/en/articles/the-core-plan/.

   - If you operate 10+ techs or expect rapid scaling and want deep analytics/enterprise modules, request a ServiceTitan demo and ROI discussion before committing [ServiceTitan pricing](https://www.servicetitan.com/pricing).  
3. Run a short pilot (use vendor trials or a sandbox): import a few customers, create quotes and jobs, test field app workflows and payment capture. 4. Validate integrations and accounting flows with a bookkeeper: confirm QuickBooks or Xero sync behavior and what fields map. 5. Compare total cost of ownership: base subscription + per‑user fees + payment processing + any onboarding or premium support fees + add‑ons you used in the pilot. Get the vendor to produce a 12‑month cost estimate in writing.
